Конфиденциальность приложения ПаркАвто

Редакция от 25 октября 2026 года

1. О приложении и операторе

Этот документ описывает обработку данных приложением «Паркавто постинг» и его интеграцией Instagram «Паркавто постинг-IG». Приложение используется ПаркАвто для управления собственными публикациями и историями, а также для работы сотрудников с обращениями клиентов в Instagram, в том числе в аккаунте parkavto_lipetsk.

Оператор: ООО «ПАРКАВТО». Адрес: 398004, Липецкая область, г. Липецк, ул. Катукова, д. 5. Электронная почта для вопросов об обработке данных: pa048@mail.ru. Сайт: автолипецк.рф.

Обработка обращений через формы сайта отдельно описана в политике обработки персональных данных пользователей сайта.

2. Какие данные получает приложение

  • Сведения о подключённом профессиональном аккаунте: идентификатор и имя пользователя, разрешения и служебный маркер доступа.
  • Для публикаций и историй: подготовленные сотрудниками тексты, фотографии и видео, идентификаторы публикаций и сведения о результате размещения.
  • Для переписки: идентификатор собеседника, доступные через API имя и имя пользователя, текст сообщений, вложения, время, идентификаторы сообщений и сведения об их доставке и изменениях.
  • Служебные сведения о работе с обращением: ответственный сотрудник, статусы, отметки, история действий и связь с карточкой клиента, если сотрудник её установил.

Перечень фактически получаемых сведений зависит от разрешений подключённого аккаунта, используемой функции и содержания обращения. ПаркАвто не запрашивает у собеседников пароль Instagram, коды подтверждения или ключи доступа.

3. Для чего используются данные

Данные используются для размещения материалов ПаркАвто, получения и отображения обращений, уведомления ответственных сотрудников, подготовки и отправки ответов, ведения истории общения и обработки запроса клиента в CRM. Служебные сведения нужны для контроля доступа, предотвращения повторной обработки сообщений и разбора ошибок.

Функции помощника могут по команде сотрудника передавать выбранный текст переписки внешнему сервису обработки текста для подготовки черновика ответа, сводки или сведений для карточки клиента. Черновик проверяет сотрудник; сам по себе он не отправляется клиенту.

4. Доступ и передача данных

Переписка доступна сотрудникам через рабочую систему с авторизацией и настройками доступа по источникам и диалогам. Служебные маркеры и секреты приложения хранятся отдельно от публичных страниц сайта.

Для отправки и получения сообщений и публикаций приложение взаимодействует с API Meta. Для работы системы могут использоваться технические подрядчики и сервисы хранения, доставки уведомлений и обработки текста в объёме, необходимом для соответствующей функции. Данные не предназначены для открытой публикации или продажи третьим лицам.

Обработка данных самой платформой Instagram регулируется её собственной политикой конфиденциальности. Этот документ описывает обработку данных со стороны ПаркАвто.

5. Хранение и прекращение обработки

Данные сохраняются для работы с обращением и историей взаимодействия. Необходимость дальнейшего хранения оценивается с учётом цели обращения, запроса пользователя и применимых обязательств оператора. Отзыв разрешений приложения прекращает соответствующий доступ к API, но сам по себе не удаляет ранее сохранённую историю из системы ПаркАвто.

Удаление сохранённых данных выполняется по обращению пользователя после проверки принадлежности данных. Если часть сведений необходимо сохранить на отдельном основании, оператор сообщает об этом в ответе на обращение. Подробный порядок описан на странице «Удаление данных приложения ПаркАвто».
